测试说明

1. 点击「三路并发写入」，三个 Dedicated Worker 会分别向 OPFS 写入测试数据，不把完整文件放进 JavaScript 内存。

2. 写入完成后，分别点击「下载文件」。Dedicated Worker 从 OPFS 按块读取，MessageChannel 将数据交给 Service Worker；Service Worker 只负责响应下载请求，不直接访问 OPFS。全程不创建 File / Blob 对象、不创建 Object URL。

3. 下载流完整结束后，页面只会提示「浏览器已读取完整数据流」，这不等同于操作系统已确认保存。请先检查下载管理器，再手动清理 OPFS 文件。

4. 本测试使用 .bin 文件验证流式下载，不代表 MP4 编码兼容性。实际摄像机 MP4 将在后续接入测试。
