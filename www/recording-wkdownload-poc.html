Luxe WKDownload 原生附件下载 POC

独立验证 Home Assistant iOS App 内置 WKWebView 能否把 HTTP 附件导航交给 App 原生 WKDownload 下载管理器。本页不连接摄像机，不调用 Recording Manager，也不修改正式录像功能。

测试数据
请求方式
用户主动点击的同源 GET 导航
文件大小
16 MiB（16,777,216 bytes）
响应类型
application/octet-stream
附件头
Content-Disposition: attachment
服务端生成
64 KiB 分块实时生成，单请求有界内存
持久化
不写 NAS、HA /media 或 go2rtc 磁盘
录像 / 缓存
不连接摄像机；不使用 Blob、OPFS 或完整文件内存缓存

预期：点击下载后，HA iOS App 应出现其原生下载管理器，并显示文件名与下载进度。

下载 16 MiB 测试文件
如何判断结果

1. 如果出现 Home Assistant 原生下载管理器，并显示文件名与下载进度，说明 WKDownload 路径已触发。

2. 下载完成后，使用原生分享入口将文件保存到「文件」App。文件应为 16 MiB。

3. 如果页面直接显示二进制乱码、空白页、HTTP 错误，或没有出现原生下载管理器，请截图并记录现象；不要据此判断 OPFS 写入失败。

4. 此测试只验证 WKDownload 接管 HTTP 附件，不代表 OPFS → go2rtc 流式中转已经实现。
